# figma-plugin-bridge-setup

一键安装 TalkToFigma 本地插件桥（Cursor ↔ Figma 桌面插件），不走 api.figma.com，不消耗官方 MCP / REST 额度。

## 给 Cursor Agent

把本仓库里的 `figma-plugin-bridge-setup/` 目录放到 `~/.cursor/skills/`（或直接下载下方 zip 丢给 Agent），然后说「按 figma-plugin-bridge-setup 安装」。

## 下载

- Release zip：见右侧 Releases
- 或本页绿色 **Code → Download ZIP**

公众号回复口令 `figma` 可获取本仓库链接。
